## 项目定位

MoonLogfmt Lens 是使用 MoonBit 原创实现的 logfmt 数据契约与日志质量工具箱。
它不负责生成或采集日志，而是对已有 logfmt 文本进行解析、契约验证、隐私
脱敏、批量画像和版本漂移分析。

## 解决的问题

logfmt 易读易写，但重复键、缺失字段、未闭合引号和控制字符会破坏自动化；
字段类型变化会让下游查询失效；新增字段还可能泄露令牌、邮箱、手机号或支付
信息。传统单行解析器通常无法解释一批日志相对于已知良好版本发生了什么变化。

## 已完成能力

- 完整解析裸值、引号值、转义、空值和 flag 字段。
- 审计语法错误、重复键、缺失键、超长值和控制字符。
- 识别 14 类语义值，包括数值、时长、时间戳、UUID、邮箱和自由文本。
- 提供带类型、必填项、长度、枚举和未知字段策略的可执行契约。
- 从样本推断字段出现率、主导类型、置信度和候选契约。
- 识别凭据、个人信息、支付信息和网络身份，并提供三种脱敏模式。
- 生成不含具体值、且不受字段顺序影响的结构指纹。
- 对批量日志执行无效率、风险分、结构数量和必填字段出现率门禁。
- 解释新增或消失字段、类型变化、长度增长、新结构和风险回归。

## 创新与价值

项目形成“解析、推断、冻结契约、隐私投影、结构指纹、漂移解释”的闭环。
同一套语义类型体系贯穿所有阶段，结构比较不保留具体日志值。公开 Mooncakes、
GitHub 和 MoonBit OSC 相关检索中，未发现具备该完整 logfmt 治理闭环的公开
MoonBit 项目。
